# Fun Lab Reports

A lab report app for a homeschooled Grade 9 student in Saskatchewan working through Apologia's *Exploring Creation with Physical Science*, 4th Edition.

**Status:** v0.3 (up to 4 data tables per lab; multiple graphs, several lines per graph). Modules 1–3 have their experiments listed; Modules 4–15 have supplies and safety notes, and experiments can be added in the Home teacher area. Safari test running on the student's MacBook.

## Files
- `fun-lab-reports.html`: the app (v0.3).
- `fun-lab-reports-safari-test.html`: checks that Safari keeps saved work and photos, and that read-aloud works. Instructions are on the page.
- `index.html`: front page with links to the app and the test.

## How the test is used
Open the test page on the MacBook in Safari today, again after quitting Safari, at 3–4 days, and after 8 or more days. Each time, press **Copy my results** and send the text to Riley.

Nothing on these pages is sent anywhere. Saved data stays in the browser on that computer.

## Updating
Download the new file → on GitHub, **Add file › Upload files** → **Commit changes**. The live page updates in about a minute.

## Where the work is saved
Reports and photos are saved in the browser on the MacBook, not on GitHub. Use **Home teacher › Download backup** once a week.
